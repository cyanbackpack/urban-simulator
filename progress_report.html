2. 시스템 아키텍처

terrain_gen.py → terrain_*.json → make_reference.py → submission_*.json → score_v2.py
webapp.py ↕ REST web/app.js → Canvas 편집기 → 실시간 채점
validate.py · render2.py · render_terrain.py · leaderboard.py · balance_test.py

웹 서버는 Flask 없이 Python 표준 라이브러리 ThreadingHTTPServer만으로 구현했으며, 채점 로직(score_v2.run)을 직접 임포트해 "화면에 보이는 도시 = 채점된 도시"를 보장합니다.

3. 완료된 작업

3-1. 지형·이벤트 생성

  • 5종 지형 아키타입: lake_core / twin_coast / mountain_gate / great_delta / central_plain
  • fBm 고도 + 수계·경사·숲·습지·농지·기후 메타데이터 레이어 (v0.4)
  • 15+ 정적 이벤트: 자원, 항만, 단층, 범람원, 태풍, 풍력, 대수층, 침하, 경관, 지열, 비옥토, 산사태 등

3-2. 채점 시스템

  • 1,000점 5축 평가 + 목적적합 보너스 + 이벤트 점수 + 난이도 계수
  • 하드 게이트 4종 (비건축지·예산·연결성·최소 인구/일자리)
  • 등급 S/A/B/C/D (950 / 850 / 720 / 580 컷)
  • 캘리브레이션: S 비율 7/25 → 0/25 (베이스라인 B 중심 정착)

3-3. 검증·시각화·도구

  • validate.py: 게이트 + 위반 좌표 샘플 출력
  • render2.py: 마스터플랜 PNG (채점기 팔레트 동기화)
  • render_terrain.py: 위성지도 스타일 상세 지형 PNG
  • preview_terrains.py: 5지형 몽타주 PNG
  • make_reference.py: 지형별 결정론적 기준 제출물
  • leaderboard.py: 폴더 일괄 채점 + CSV + 누적막대 PNG
  • balance_test.py: 5지형 × 5목적 = 25조합 자동 스윕

3-4. 웹 UI (브라우저 편집기)

  • webapp.py: stdlib 서버, 9개 REST 엔드포인트, 경로 traversal 방어
  • 지형 드롭다운 → Canvas 래스터 렌더링 (지형·이벤트·범례)
  • 존 드로잉: 클릭 정점 추가, Enter/더블클릭/시작점 클릭으로 자동 닫기
  • 교통·시설·역·허브·이벤트 배치 도구 (단축키 V/Z/T/F/S/H/E)
  • 드래그: 존 정점·시설·이벤트 끌기, 드래그 중 좌표/면적 표시
  • Undo / Redo (JSON 스냅샷, Ctrl+Z / Ctrl+Y)
  • 겹침 경고 배너 (폴리곤 커밋 시 자동 검사)
  • 존 색상·라벨: CBD/주거/산업/공공/녹지 카테고리 팔레트 + 지도 위 칩
  • 이벤트 인스펙터: 클릭 → 종류·효과 설명·이번 채점 gain/loss/net 표시
  • 이벤트 추가/이동/삭제 + POST /api/score의 events 오버라이드로 즉시 채점
  • 역·허브 인캔버스 배치/드래그/삭제 + 허브 수 → 교통축 점수 연동
  • 스냅/그리드: 0.5/1/2.5 km 격자 표시 + 정점·점 배치를 격자에 스냅
  • 리더보드 모달: 폴더 일괄 채점 → 점수순 표 + 현재 작업 행 + "불러오기"
  • 5축 미니 막대, 등급 뱃지, 예산·이벤트·게이트 실패 사유 표시

4. 채점 공식 (캘리브레이션 후)

base_1000 = Σ axis_score(w_i × axis_i) — 5축 가중합
eff_diff = 1 + (difficulty − 1) × DIFF_GAIN
fit_bonus = fit_score × FIT_BONUS_MAX
ev_total = Σ(pos × EVENT_POS_GAIN − neg)
final = (base_1000 + fit_bonus + ev_total) × eff_diff
DIFF_GAIN
0.5
난이도 효과 압축. 0이면 난이도 무효, 1이면 원본 배율 그대로
ECONOMY_STRETCH
1.20
경제축 포화 방지. 목표 대비 20% 초과 달성이 만점 기준
FIT_BONUS_MAX
85
목적적합 보너스 상한. (이전: 100점 → 감쇠)
EVENT_POS_GAIN
0.75
기회 이벤트 보너스 감쇠. 재난 페널티는 그대로(1.0)

6. 웹 UI 편집기 기능 상세

▭ 존 편집

  • 클릭으로 정점 추가, Enter/더블클릭/시작점 근처 클릭으로 자동 닫기
  • 그리는 동안 면적(km²) 실시간 표시
  • CBD/상업·주거·산업물류·공공·녹지 팔레트
  • 지도 위 색상 라벨 칩

↖ 선택 · 드래그

  • 선택 모드(V)에서 정점·시설·이벤트 끌기
  • 드래그 중 좌표(m) 및 면적(km²) 표시
  • Del 키로 선택 항목 삭제

↶ Undo / Redo

  • 모든 편집(그리기·드래그·삭제)에 대해 동작
  • Ctrl+Z / Ctrl+Y, 툴바 버튼
  • JSON 스냅샷 스택

◎ 이벤트 편집

  • 클릭 → 인스펙터: 종류·효과 설명·점수 반영 확인
  • 이벤트 추가(반경 지정)·이동·삭제
  • 채점 시 실제 scorer가 이벤트 변화를 반영

● ◉ 역 · 허브

  • 인캔버스 배치/드래그/삭제
  • 허브 개수 → 교통축 점수(t_hub) 반영
  • 예산 계산에도 반영

⊞ 스냅 / 그리드

  • 0.5 / 1 / 2.5 km 격자 표시
  • 정점·점 배치 및 드래그를 격자에 스냅
  • 격자 밀도 자동 조정 (줌 대응)

⚠ 겹침 경고

  • 폴리곤 확정 시 기존 존과 교차 검사
  • 겹칠 경우 배너 4초 표시
  • SAT 기반 폴리곤 교차 알고리즘

🏆 리더보드

  • submissions 폴더 일괄 채점 → 점수순 표
  • 현재 작업 행 강조 삽입
  • 5축 미니 막대 비교, "불러오기"로 편집기 로드
